# Student-Performance-Analytics

## Objective

Transform raw, multi-department educational records into interactive, descriptive decision 
intelligence to monitor student outcomes, track semester trends, and triage at-risk cohorts.

##Summary

Educators, department heads, and institutional analysts require efficient methodologies to evaluate student 
outcomes at scale across multiple departments, semesters, and individual course modules. Raw tabular grade 
spreadsheets are dense, making overall performance trends and critical student risks difficult to identify rapidly. 
This project bridges that gap by ingesting raw, row-level student records 
(StudentPerformance_Combined.xlsx) and transforming them into a cohesive, interactive Power BI 
dashboard.
